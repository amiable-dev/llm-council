# Packaged rubric exemplars

Copies of the two promotion-rubric anchor notes, shipped with the npm package
so `kb init` can seed a fresh repository whose rubric has working exemplars
(ADR-004: judgment is calibrated against fixed reference points, hash-pinned
per task by the envelope). In THIS repository the rubric anchors to the live
notes under concepts/; these copies exist for packaging and are refreshed
manually if the anchor notes change.
